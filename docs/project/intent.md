# Intent

## Purpose
A dashboard for retail traders to analyze NSE stocks with technical indicators and automated buy/sell signals, enabling data-driven trading decisions for a curated Nifty-100 stock list.

## Goals
- G1: Generate buy/sell signals through Moving Average Crossover strategy on NSE stocks
- G2: Provide technical analysis via 10+ indicators (SMA, EMA, RSI, Bollinger Bands, MACD, Stochastic, ATR, VWAP, OBV, Parabolic SAR)
- G3: Enable retail traders to track manual positions and see real profit/loss calculations
- G4: Ensure secure, persistent access to positions and analysis with user authentication

## Not goals
- Real-time intraday data (end-of-day only)
- Automated trading execution or broker connectivity
- AI-powered recommendations, sentiment analysis, or news summaries
- Full NSE universe (Nifty 100 curated list only)
- Multi-strategy comparison or library
- CSV/broker import for positions
- Aggregate portfolio P&L or advanced analytics

## Success
- Moving Average Crossover signals are generated and displayed on price charts for NSE Nifty-100 stocks
- Users can manually enter positions and view accurate per-lot P&L against current market prices
- 10+ technical indicators are available and togglable on charts for analysis
- User positions persist securely across sessions with email/password authentication
